# Big-data-project
1. Giới thiệu

Dự án xây dựng hệ thống thu thập, lưu trữ, xử lý và phân tích dữ liệu thương mại điện tử bằng các công nghệ Big Data.

2. Công nghệ sử dụng

Apache Kafka: thu thập dữ liệu streaming.

MySQL và Apache Sqoop: lưu trữ dữ liệu quan hệ và nhập dữ liệu batch.

Hadoop HDFS: lưu trữ dữ liệu phân tán.

Apache Spark: làm sạch và tổng hợp dữ liệu.

Spark SQL hoặc Apache Hive: truy vấn và phân tích dữ liệu.

3. Cấu trúc dự án

01_streaming/: thu thập dữ liệu liên tục.

02_batch_sqoop/: nhập dữ liệu từ MySQL.

03_storage_hdfs/: thiết kế lưu trữ trên HDFS.

04_processing_spark/: xử lý dữ liệu bằng Spark.

05_analytics/: truy vấn và phân tích.

docs/: tài liệu, sơ đồ và minh chứng.
